Aplikacja „Koala Kids Studio Automator”

To wewnętrzne narzędzie właściciela kanału. Służy wyłącznie do zarządzania własnym kanałem Koala Kids Studio: ustawiania tytułów, opisów, miniatur, napisów, playlist i terminów publikacji oraz odczytu statystyk kanału. Aplikacja nie jest udostępniana innym osobom.

  • Jakie dane: wyłącznie dane własnego kanału pobierane przez YouTube Data API i YouTube Analytics API (metadane filmów, napisy, zbiorcze statystyki oglądalności). Aplikacja nie zbiera danych widzów ani innych użytkowników i nie przetwarza danych osobowych dzieci.
  • Przechowywanie: token dostępu i raporty statystyk są przechowywane na prywatnym serwerze właściciela kanału.
  • Udostępnianie: dane nie są sprzedawane, udostępniane ani przekazywane osobom trzecim.
  • Cofnięcie dostępu: w każdej chwili na myaccount.google.com/permissions.

Aplikacja korzysta z usług YouTube API Services. Obowiązują Warunki korzystania z YouTube i Polityka prywatności Google.

The "Koala Kids Studio Automator" app

An internal tool of the channel owner, used only to manage the owner's own Koala Kids Studio channel: setting titles, descriptions, thumbnails, captions, playlists and publish dates, and reading the channel's own analytics. The app is not offered to anyone else.

  • Data: only data of the channel itself, obtained through the YouTube Data API and YouTube Analytics API (video metadata, captions, aggregated viewing statistics). The app does not collect data about viewers or any other users and does not process personal data of children.
  • Storage: the access token and analytics reports are stored on the channel owner's private server.
  • Sharing: data is never sold, shared or transferred to third parties.
  • Revoking access: at any time at myaccount.google.com/permissions.
